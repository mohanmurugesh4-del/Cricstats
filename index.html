CRICSTATS

Every delivery is an immutable event. Batting, bowling, extras, partnerships and run rates are worked out from those events, so undo is simply: drop the last one and replay.

How it works

One event log.
Every figure derived.

Nothing on a scorecard is typed in by hand. The engine validates each ball, applies it to the innings state, then computes the statistics from that state.

01

Ball event

One immutable record: bowler, runs off the bat, extra type, wicket and fielder.

02

Validate

Rejects a bowler who bowled the last over, a wicket that clashes with its extra, a fielder from the wrong side.

03

Apply

Moves the score, strike and over count, and closes partnerships at each wicket.

04

Derive

Batting, bowling, fall of wickets, run rate, required rate and player-of-the-match points.

def undo(self) -> bool:
    if not self.events:
        return False
    kept = self.events[:-1]
    self.events = []
    self._reset()
    for b in kept:   # state is purely derived
        self._apply(b)
        self.events.append(b)
    return True

Undo has no special case. The engine never edits state in place, so rewinding a mistake is the same replay used for every other ball. That is why a wrongly scored delivery can always be fixed without a stale total anywhere.

What it computes

Everything
a scorer checks

R·B

Batting

Runs, balls faced, fours, sixes and strike rate for every batter, with how each one was out.

O·M

Bowling

Overs, maidens, runs, wickets, economy, wides and no-balls. Byes are not charged to the bowler.

+ex

Extras

Byes, leg byes, wides and no-balls kept apart, with the penalty run on each illegal delivery.

2-41

Fall of wickets

Each wicket with the score and the over it fell in, in the order they came.

P·B

Partnerships

Runs and balls per pair, with each batter's share and extras. The unbroken stand is marked live.

RRR

Run rates

Current run rate, and in a chase the runs needed and the rate required from here.

Get it running

One command.
Standard library only.

Save the file as cricstats.py and run it. It asks for the two teams, their batting order, the overs and who bats first, then scores the match in the terminal with the same rules as this page.

$ python cricstats.py
